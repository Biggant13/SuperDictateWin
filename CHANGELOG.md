# История изменений (Changelog)

Все значимые изменения в проекте документируются в этом файле.

### [Unreleased] - Расширенная статистика и работа с логами

**Улучшения интерфейса (Трей):**
- В меню трея теперь отображается текущая версия программы (например, `SuperDictate v1.6.0`).
- Статистика разделена на два показателя: **«📅 Сегодня»** (счетчик сбрасывается в полночь) и **«🏆 Всего»** (общий счетчик за всё время).
- Добавлен пункт **«Открыть лог»**, который мгновенно открывает файл `superdictate.log` в системном текстовом редакторе для быстрой диагностики проблем.

**Прочее:**
- Добавлен модуль `core/version.py` для централизованного хранения номера версии.
- Для Windows добавлен автоматически собираемый установщик `SuperDictate-Setup.exe` (Inno Setup), который создает ярлыки в меню Пуск и на рабочем столе.
- Версия программы (`core/version.py`) и версия установщика (`installer.iss`) теперь автоматически синхронизируются с именем Git-тега при сборке в GitHub Actions.

**Настройки:**
- Добавлена возможность выбора конкретного микрофона в окне настроек (полезно, если в системе несколько устройств записи). Выбранное устройство применяется без перезапуска программы.

### [v1.5.1] - Хотфикс (текущая стабильная)

**Исправления:**
- Сделан безопасный импорт библиотеки `evdev`. Теперь приложение не падает с ошибкой `ModuleNotFoundError` при запуске на Windows или Linux без установленного `evdev`. 
- Для работы Wayland-бэкенда по-прежнему требуется установка `evdev` (автоматизировано в скрипте установки).

### [v1.5.0] - Поддержка Wayland и автоустановка

**Поддержка Wayland (Linux):**
- Добавлен альтернативный бэкенд на базе библиотеки `evdev` для перехвата горячих клавиш в графической сессии Wayland.
- Программа теперь автоматически определяет тип сессии (`XDG_SESSION_TYPE`) и выбирает нужный бэкенд: `pynput` для X11/Windows и `evdev` для Wayland.
- Добавлен скрипт автоматической установки для Linux (`install_superdictate.sh`), который скачивает последнюю версию, создает ярлык и настраивает права доступа (добавляет пользователя в группу `input`, необходимую для работы `evdev`).

### [v1.4.0] - Улучшение стабильности и логирования

**Логирование и отладка:**
- Добавлен модуль `core/logger.py`. Теперь все системные сообщения и ошибки записываются в файл `superdictate.log` рядом с исполняемым файлом (или в корне проекта).
- Настроена ротация логов (файл ограничен 5 МБ, хранится 2 резервные копии), чтобы не засорять жесткий диск.
- Все стандартные выводы (`print`) и необработанные исключения теперь автоматически перехватываются логгером. Это решает проблему «молчаливых» падений приложения в оконном режиме (без консоли).
- Уровень предупреждений от сторонних библиотек (`stderr`) снижен до `WARNING`, чтобы они не засоряли лог как критические ошибки.
- Добавлен пакет `hf_xet` в зависимости для аппаратного ускорения скачивания моделей с Hugging Face.

**Воспроизводимость сборки:**
- Версии всех библиотек в `requirements.txt` жестко зафиксированы (через `==`). Это гарантирует, что приложение будет собираться и работать одинаково стабильно в будущем, даже если выйдут новые версии зависимостей.
- Инструменты для разработки и сборки (например, `PyInstaller`) вынесены в отдельный файл `requirements-dev.txt`, чтобы не засорять окружение обычных пользователей.
- GitHub Actions переведен на использование `requirements-dev.txt` для автоматических сборок.

### [v1.3.2] - Обновление документации

- В README добавлен раздел с решением проблемы ложных срабатываний Windows Defender (инструкция по добавлению программы в исключения).
- Исправлено форматирование разделов в файле документации.

### [v1.3.1] - Хотфикс

**Исправление критических ошибок:**
- Исправлено падение приложения при первом запуске собранной версии (`.exe` или Linux-бинарник) в момент скачивания модели. Ранее процесс завершался с ошибкой `AttributeError: 'NoneType' object has no attribute 'write'`.
- Отключены прогресс-бары библиотеки `huggingface_hub` (которая использует `tqdm`). В оконном режиме (без консоли) они пытались писать в несуществующий поток вывода и вызывали краш.
- Добавлена глобальная страховка: если приложение запущено без консоли, потоки `sys.stdout` и `sys.stderr` перенаправляются в `devnull`. Это защищает от подобных ошибок в любых сторонних библиотеках.

**Прочее:**
- Папка `dist/` (локальные артефакты сборки PyInstaller) исключена из git-трекинга и добавлена в `.gitignore`. Теперь локальные сборки не засоряют историю коммитов.

### [v1.3.0] - Кроссплатформенность и CI/CD

**Поддержка Linux (новая платформа):**

- Добавлен полноценный порт для Linux (X11). Программа работает на Ubuntu 22.04+, Debian 12+, Fedora 38+ и других современных дистрибутивах.
- Платформозависимый код вынесен в отдельный слой `core/platform/` с абстракцией `BasePlatform`:
  - `windows.py` — прежняя реализация через `ctypes.windll` (без изменений в поведении).
  - `linux.py` — реализация через `pynput` и `tkinter` (симуляция клавиш, настройка оверлея без захвата фокуса).
  - `__init__.py` — фабрика `get_platform()`, выбирающая бэкенд по `platform.system()`.
- Вся бизнес-логика (аудио, распознавание, форматирование, статистика, трей) осталась общей для обеих ОС — дублирования кода нет.

**Совместимость и системные зависимости:**

- На Linux требуются системные пакеты: `python3-tk`, `libportaudio2`, `xclip`, `libayatana-appindicator3-1` (инструкции по дистрибутивам — в разделе «Установка → Linux»).
- `core/config.py`: исправлен `BASE_DIR` для frozen-режима — теперь `config.json` создаётся рядом с исполняемым файлом, а не в родительской папке.
- `SuperDictate.spec` стал платформо-зависимым: разные `hiddenimports` для `pynput` (`_win32` / `_xorg`) и `pystray` (`_win32` / `_xorg`) в зависимости от ОС сборки. `config.json` теперь опционален — если его нет в исходниках, он создаётся при первом запуске.

**CI/CD:**

- Добавлен GitHub Actions workflow (`.github/workflows/build.yml`) с матричной сборкой:
  - `windows-latest` → `SuperDictate-Windows.zip`
  - `ubuntu-22.04` → `SuperDictate-Linux.tar.gz` (сборка на 22.04 для совместимости с glibc 2.35+)
- Публикация релиза автоматическая: при пуше тега `v*` создаётся GitHub Release со всеми артефактами и авто-сгенерированными release notes.
- Возможен ручной запуск из вкладки Actions (`workflow_dispatch`) — для проверки сборки без релиза.

**Прочее:**

- `stats.json` исключён из git-трекинга (это runtime-данные, а не исходники). Добавлен в `.gitignore`.

**Ограничения:**

- Linux-версия требует графическую сессию X11. В Wayland глобальные хоткеи и симуляция клавиш не работают из-за политики безопасности — поддержка Wayland запланирована отдельно.

### [v1.2.0] - Полировка и Статистика

**Новый функционал:**

- Добавлено графическое окно настроек (доступно из трея). Теперь можно менять горячую клавишу, положение оверлея и звук без редактирования `config.json`.
- Добавлен динамический счетчик статистики в трее: приложение считает количество распознанных слов и показывает примерное сэкономленное время (обновляется в реальном времени).
- Улучшена логика умного форматирования текста (чтение контекста вокруг курсора).

### [v1.0.0] - Первый публичный релиз

**Архитектура и интерфейс:**

- Полный рефакторинг кода: проект разбит на модули (`core/audio.py`, `core/transcriber.py`, `core/ui.py`, `core/utils.py`, `core/tray.py`).
- Добавлена иконка в системный трей (`pystray`) с меню корректного выхода.
- В оверлей добавлен статус «⏳ Перевожу в текст...» во время работы нейросети.
- Добавлены ненавязчивые звуковые сигналы (мягкая синусоида) при старте (400 Гц) и остановке (600 Гц) записи.
- В меню трея добавлен переключатель звука с сохранением состояния в `config.json`.

**Умное форматирование (Контекстный ридер):**

- Реализован алгоритм чтения контекста вокруг курсора (через эмуляцию `Ctrl+C` и `Shift+Left/Right`).
- **Умная капитализация**: при диктовке после точки ставится заглавная буква, в середине предложения — строчная.
- **Бесшовная замена**: при выделении слова двойным кликом программа сохраняет оригинальный регистр, пунктуацию и пробелы.
- **Защита от склеивания**: программа автоматически добавляет пробелы, если курсор стоит вплотную к тексту или знакам препинания.
- Упрощена логика для обычной диктовки (программа доверяет расстановку точек нейросети GigaAM).

### [v0.8.0] - Переход на GigaAM v3

- Отказ от `faster-whisper` в пользу GigaAM v3 (RNN-T) от Сбера — значительный прирост качества распознавания русского языка и скорости работы на CPU.
- Интеграция через библиотеку `onnx-asr`.
- Добавлена поддержка полностью офлайн-режима: модель скачивается локально (`download_model.py`), и приложение не требует интернета.
- Обновлен `SuperDictate.spec` для сборки в `.exe` (PyInstaller) с учетом новых зависимостей.

### [v0.5.0] - Эксперименты с моделями и режимами

- Реализован режим встречи (`F8`) с записью системного звука (loopback) и сохранением текста в файл.
- Режим встречи (`F8`) удален из-за избыточности и сложности поддержки. Фокус смещен на идеальную push-to-talk диктовку (`F9`).
- Проведены тесты моделей Whisper (tiny, medium, large-v3-turbo), по итогам которых выбран оптимальный баланс скорости и качества.

### [v0.1.0] - Первая рабочая версия (MVP)

- Базовый скрипт на базе `faster-whisper` (модель small).
- Глобальная горячая клавиша `F9` (push-to-talk).
- Автоматическая вставка текста в активное окно через буфер обмена и эмуляцию `Ctrl+V`.
- Реализован оверлей «🔴 Идёт запись...» поверх всех окон (без перехвата фокуса).
- Добавлена защита от галлюцинаций нейросети на тишине (фильтры VAD и проверка RMS).
- Вынос всех настроек (горячая клавиша, модель, язык) в файл `config.json`.
