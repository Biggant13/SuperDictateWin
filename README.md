# SuperDictate for Windows 🎤

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![Platform](https://img.shields.io/badge/Platform-Windows%2010%2F11-lightgrey)
![License](https://img.shields.io/badge/License-MIT-green)

Локальная, полностью офлайн-диктовка для Windows, работающая на базе передовой русскоязычной модели **GigaAM v3** от Сбера. Приложение работает в фоне, не отправляет ваши голосовые данные в облако и активируется по горячей клавише (по умолчанию **F9**).

> **Форк проекта [shlgd/SuperDictate](https://github.com/shlgd/SuperDictate)** (оригинальная версия для macOS), адаптированный под Windows с использованием ONNX Runtime и GigaAM.

---

## ✨ Особенности

- **100% Офлайн**: аудио обрабатывается локально, никакие данные не уходят в сеть.
- **Высокая точность**: модель GigaAM v3 (RNN-T) показывает отличные результаты на русском языке, расставляет знаки препинания и заглавные буквы.
- **Push-to-talk**: Зажмите `F9`, говорите, отпустите — текст мгновенно вставится в активное окно (браузер, мессенджер, редактор кода).
- **Ненавязчивый интерфейс**: Небольшой оверлей поверх всех окон показывает, что идёт запись, а иконка в системном трее позволяет быстро выйти из приложения.
- **Быстрый старт**: Благодаря использованию `onnx-asr` и квантованной модели, распознавание работает быстро даже на CPU без видеокарты.
- **Удобный интерфейс**: Иконка в системном трее с меню настроек, переключателем звука и **динамической статистикой** сэкономленного времени.
- **Графические настройки**: Возможность менять горячую клавишу, положение оверлея и звук через удобное окно (без редактирования JSON).
- **Умная вставка**: Анализ контекста (символы вокруг курсора) для автоматической расстановки пробелов, знаков препинания и заглавных букв.

## 🚀 Использование готового дистрибутива (из папки `dist`)

В репозитории уже собран готовый к запуску дистрибутив (в папке `dist/SuperDictate`), но **без самой модели** (из-за ограничений GitHub на размер файлов).

### Шаг 1: Скачайте модель

Модель весит около 900 МБ. Скачать её можно с Hugging Face. Убедитесь, что у вас установлен Python и пакет `huggingface_hub`, затем выполните в корне проекта:

```bash
python download_model.py
```

Скрипт создаст папку `gigaam-v3-e2e-rnnt-onnx` со всеми необходимыми файлами.

### Шаг 2: Поместите модель рядом с `.exe`

Скопируйте папку `gigaam-v3-e2e-rnnt-onnx` в папку `dist/SuperDictate/`. Итоговая структура должна выглядеть так:

```text
dist/SuperDictate/
├── SuperDictate.exe
├── config.json
├── _internal/
└── gigaam-v3-e2e-rnnt-onnx/   <-- сюда
    ├── v3_e2e_rnnt_encoder.onnx
    └── ...
```

### Шаг 3: Запуск

1. Запустите `SuperDictate.exe`. В системном трее (возле часов) появится красная иконка.
2. Нажмите и удерживайте `F9`.
3. Скажите фразу (например, «Привет, как дела»).
4. Отпустите `F9` — текст вставится в активное окно.

> **Важно:** Приложение может потребовать установленный Microsoft Visual C++ Redistributable (x64), если он ещё не установлен в системе.

## 🛠 Установка и запуск из исходников

Если вы хотите запустить проект в режиме разработки или внести изменения:

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Biggant13/SuperDictateWin.git
cd SuperDictateWin
```

2. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

3. Скачайте модель (если ещё не сделали этого):

```bash
python download_model.py
```

4. Запустите приложение:

```bash
python super_dictate_win.py
```

## ⚙️ Настройка (`config.json`)

Все настройки находятся в файле `config.json` в корне проекта (или рядом с `.exe`).

```json
{
  "hotkey": "f9",
  "model_name": "gigaam-v3-e2e-rnnt",
  "model_path": "./gigaam-v3-e2e-rnnt-onnx",
  "language": "ru",
  "overlay_position": "bottom"
}
```

| Параметр | Описание |
| --- | --- |
| `hotkey` | Клавиша активации записи. Можно использовать `f9`, `ctrl+space`, `alt+d` и т.д. |
| `model_name` | Имя модели для `onnx-asr` (по умолчанию `gigaam-v3-e2e-rnnt`). |
| `model_path` | Путь к папке с ONNX-моделью. Если пусто или папки нет, приложение попытается скачать модель с Hugging Face. |
| `overlay_position` | Позиция окна записи: `bottom` (снизу) или `top` (сверху). |

## 📦 Сборка `.exe` (PyInstaller)

Для создания независимого исполняемого файла:

1. Установите PyInstaller:

```bash
pip install pyinstaller
```

2. Запустите сборку:

```bash
pyinstaller --clean --noconfirm SuperDictate.spec
```

Готовое приложение будет находиться в папке `dist/SuperDictate/`. Не забудьте скопировать туда папку с моделью (см. раздел «Использование готового дистрибутива»).

## 📜 История изменений (Changelog)

Все значимые изменения в проекте документируются в этом файле.

### [v1.2.0] - Полировка и Статистика
**Новый функционал:**
- Добавлено графическое окно настроек (доступно из трея). Теперь можно менять горячую клавишу, положение оверлея и звук без редактирования `config.json`.
- Добавлен динамический счетчик статистики в трее: приложение считает количество распознанных слов и показывает примерное сэкономленное время (обновляется в реальном времени).
- Улучшена логика умного форматирования текста (чтение контекста вокруг курсора).

### [v1.0.0] - Текущая стабильная версия
**Архитектура и интерфейс:**
- Полный рефакторинг кода: проект разбит на модули (`core/audio.py`, `core/transcriber.py`, `core/ui.py`, `core/utils.py`, `core/tray.py`).
- Добавлена иконка в системный трей (`pystray`) с меню корректного выхода.
- В оверлей добавлен статус «⏳ Перевожу в текст...» во время работы нейросети.
- Добавлены ненавязчивые звуковые сигналы (мягкая синусоида) при старте (400 Гц) и остановке (600 Гц) записи.
- В меню трея добавлен переключатель звука с сохранением состояния в `config.json`.

**Умное форматирование (Контекстный ридер):**
- Реализован алгоритм чтения контекста вокруг курсора (через эмуляцию `Ctrl+C` и `Shift+Left/Right`).
- **Умная капитализация**: при диктовке после точки ставится заглавная буква, в середине предложения — строчная.
- **Бесшовная замена**: при выделении слова двойным кликом программа сохраняет оригинальный регистр, пунктуацию и пробелы.
- **Защита от склеивания**: программа автоматически добавляет пробелы, если курсор стоит вплотную к тексту или знакам препинания.
- Упрощена логика для обычной диктовки (программа доверяет расстановку точек нейросети GigaAM).

### [v0.8.0] - Переход на GigaAM v3
- Отказ от `faster-whisper` в пользу **GigaAM v3 (RNN-T)** от Сбера — значительный прирост качества распознавания русского языка и скорости работы на CPU.
- Интеграция через библиотеку `onnx-asr`.
- Добавлена поддержка **полностью офлайн-режима**: модель скачивается локально (`download_model.py`), и приложение не требует интернета.
- Обновлен `SuperDictate.spec` для сборки в `.exe` (PyInstaller) с учетом новых зависимостей.

### [v0.5.0] - Эксперименты с моделями и режимами
- Реализован режим встречи (F8) с записью системного звука (loopback) и сохранением текста в файл.
- **Режим встречи (F8) удален** из-за избыточности и сложности поддержки. Фокус смещен на идеальную push-to-talk диктовку (F9).
- Проведены тесты моделей Whisper (`tiny`, `medium`, `large-v3-turbo`), по итогам которых выбран оптимальный баланс скорости и качества.

### [v0.1.0] - Первая рабочая версия (MVP)
- Базовый скрипт на базе `faster-whisper` (модель `small`).
- Глобальная горячая клавиша F9 (push-to-talk).
- Автоматическая вставка текста в активное окно через буфер обмена и эмуляцию `Ctrl+V`.
- Реализован оверлей «🔴 Идёт запись...» поверх всех окон (без перехвата фокуса).
- Добавлена защита от галлюцинаций нейросети на тишине (фильтры VAD и проверка RMS).
- Вынос всех настроек (горячая клавиша, модель, язык) в файл `config.json`.
