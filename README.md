# SuperDictate for Windows 🎤

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![Platform](https://img.shields.io/badge/Platform-Windows%2010%2F11-lightgrey)
![License](https://img.shields.io/badge/License-MIT-green)

Локальная, полностью офлайн-диктовка для Windows, работающая на базе передовой русскоязычной модели **GigaAM v3** от Сбера. Приложение работает в фоне, не отправляет ваши голосовые данные в облако и активируется по горячей клавише (по умолчанию **F9**).

> **Форк проекта [shlgd/SuperDictate](https://github.com/shlgd/SuperDictate)** (оригинальная версия для macOS), адаптированный под Windows с использованием ONNX Runtime и GigaAM.

---

## ✨ Особенности

- **100% Офлайн**: аудио обрабатывается локально, никакие данные не уходят в сеть.
- **Высокая точность**: модель GigaAM v3 (RNN-T) показывает отличные результаты на русском языке, расставляет знаки препинания и заглавные буквы.
- **Push-to-talk**: Зажмите `F9`, говорите, отпустите — текст мгновенно вставится в активное окно (браузер, мессенджер, редактор кода).
- **Ненавязчивый интерфейс**: Небольшой оверлей поверх всех окон показывает, что идёт запись, а иконка в системном трее позволяет быстро выйти из приложения.
- **Быстрый старт**: Благодаря использованию `onnx-asr` и квантованной модели, распознавание работает быстро даже на CPU без видеокарты.

## 🚀 Использование готового дистрибутива (из папки `dist`)

В репозитории уже собран готовый к запуску дистрибутив (в папке `dist/SuperDictate`), но **без самой модели** (из-за ограничений GitHub на размер файлов).

### Шаг 1: Скачайте модель

Модель весит около 900 МБ. Скачать её можно с Hugging Face. Убедитесь, что у вас установлен Python и пакет `huggingface_hub`, затем выполните в корне проекта:

```bash
python download_model.py
```

Скрипт создаст папку `gigaam-v3-e2e-rnnt-onnx` со всеми необходимыми файлами.

### Шаг 2: Поместите модель рядом с `.exe`

Скопируйте папку `gigaam-v3-e2e-rnnt-onnx` в папку `dist/SuperDictate/`. Итоговая структура должна выглядеть так:

```text
dist/SuperDictate/
├── SuperDictate.exe
├── config.json
├── _internal/
└── gigaam-v3-e2e-rnnt-onnx/   <-- сюда
    ├── v3_e2e_rnnt_encoder.onnx
    └── ...
```

### Шаг 3: Запуск

1. Запустите `SuperDictate.exe`. В системном трее (возле часов) появится красная иконка.
2. Нажмите и удерживайте `F9`.
3. Скажите фразу (например, «Привет, как дела»).
4. Отпустите `F9` — текст вставится в активное окно.

> **Важно:** Приложение может потребовать установленный Microsoft Visual C++ Redistributable (x64), если он ещё не установлен в системе.

## 🛠 Установка и запуск из исходников

Если вы хотите запустить проект в режиме разработки или внести изменения:

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Biggant13/SuperDictateWin.git
cd SuperDictateWin
```

2. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

3. Скачайте модель (если ещё не сделали этого):

```bash
python download_model.py
```

4. Запустите приложение:

```bash
python super_dictate_win.py
```

## ⚙️ Настройка (`config.json`)

Все настройки находятся в файле `config.json` в корне проекта (или рядом с `.exe`).

```json
{
  "hotkey": "f9",
  "model_name": "gigaam-v3-e2e-rnnt",
  "model_path": "./gigaam-v3-e2e-rnnt-onnx",
  "language": "ru",
  "overlay_position": "bottom"
}
```

| Параметр | Описание |
| --- | --- |
| `hotkey` | Клавиша активации записи. Можно использовать `f9`, `ctrl+space`, `alt+d` и т.д. |
| `model_name` | Имя модели для `onnx-asr` (по умолчанию `gigaam-v3-e2e-rnnt`). |
| `model_path` | Путь к папке с ONNX-моделью. Если пусто или папки нет, приложение попытается скачать модель с Hugging Face. |
| `overlay_position` | Позиция окна записи: `bottom` (снизу) или `top` (сверху). |

## 📦 Сборка `.exe` (PyInstaller)

Для создания независимого исполняемого файла:

1. Установите PyInstaller:

```bash
pip install pyinstaller
```

2. Запустите сборку:

```bash
pyinstaller --clean --noconfirm SuperDictate.spec
```

Готовое приложение будет находиться в папке `dist/SuperDictate/`. Не забудьте скопировать туда папку с моделью (см. раздел «Использование готового дистрибутива»).
