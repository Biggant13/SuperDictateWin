# SuperDictate for Windows 🎤

Локальная диктовка для Windows 10/11 с использованием модели **GigaAM v3** от Сбера. 
Приложение работает в фоне, не отправляет данные в облако и активируется по горячей клавише (по умолчанию F9).

## Возможности
- **Полностью офлайн**: аудио не покидает ваш компьютер.
- **Модель GigaAM v3**: отличное распознавание русского языка с пунктуацией.
- **Push-to-talk**: зажмите F9, говорите, отпустите — текст вставится в активное окно.
- **Оверлей**: небольшое окно поверх всех приложений показывает, что идет запись.
- **Трей**: иконка в системном трее с меню выхода.
