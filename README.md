# SuperDictate 🎤

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux-lightgrey)
![License](https://img.shields.io/badge/License-MIT-green)

Локальная, полностью офлайн-диктовка для **Windows и Linux**, работающая на базе передовой русскоязычной модели **GigaAM v3** от Сбера. Приложение работает в фоне, не отправляет ваши голосовые данные в облако и активируется по горячей клавише (по умолчанию **F9**).

> **Форк проекта [shlgd/SuperDictate](https://github.com/shlgd/SuperDictate)** (оригинальная версия для macOS), портированный на Windows и Linux с использованием ONNX Runtime и GigaAM.

---

## ✨ Особенности

- **100% Офлайн**: аудио обрабатывается локально, никакие данные не уходят в сеть.
- **Высокая точность**: модель GigaAM v3 (RNN-T) показывает отличные результаты на русском языке, расставляет знаки препинания и заглавные буквы.
- **Push-to-talk**: Зажмите `F9`, говорите, отпустите — текст мгновенно вставится в активное окно (браузер, мессенджер, редактор кода).
- **Ненавязчивый интерфейс**: Небольшой оверлей поверх всех окон показывает, что идёт запись, а иконка в системном трее позволяет быстро выйти из приложения.
- **Быстрый старт**: Благодаря использованию `onnx-asr` и квантованной модели, распознавание работает быстро даже на CPU без видеокарты.
- **Удобный интерфейс**: Иконка в системном трее с меню настроек, переключателем звука и **динамической статистикой** сэкономленного времени.
- **Графические настройки**: Возможность менять горячую клавишу, положение оверлея и звук через удобное окно (без редактирования JSON).
- **Умная вставка**: Анализ контекста (символы вокруг курсора) для автоматической расстановки пробелов, знаков препинания и заглавных букв.
- **Кроссплатформенность**: Единая кодовая база для Windows и Linux (X11).

## 📦 Установка

### Windows

**Вариант 1. Готовый релиз (рекомендуется)**

1. Скачайте `SuperDictate-Windows.zip` со страницы [Releases](../../releases/latest).
2. Распакуйте архив в любую папку (например, `C:\Program Files\SuperDictate\` или `%LOCALAPPDATA%\SuperDictate\`).
3. Запустите `SuperDictate.exe`.
4. При первом запуске модель GigaAM (~850 МБ) скачается автоматически. Требуется интернет **только для первой загрузки** — дальше всё работает офлайн.

> ⚠️ Не запускайте `.exe` изнутри zip-архива — Windows создаст временную папку, и `config.json` будет теряться при перезапуске. Обязательно распакуйте.

> **Важно:** Приложение может потребовать установленный Microsoft Visual C++ Redistributable (x64), если он ещё не установлен в системе.

**Вариант 2. Из исходников**

```powershell
git clone https://github.com/Biggant13/SuperDictateWin.git
cd SuperDictateWin
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Требования: Windows 10/11, Python 3.10+ (для варианта 2), микрофон.

#### 🛡️ Windows Defender ругается на программу (ложное срабатывание)

Поскольку `SuperDictate.exe` собирается с помощью PyInstaller, упаковывается в архив и **не имеет цифровой подписи** (стоимость подписи для Open Source-проектов высока), Windows Defender и антивирусы (Kaspersky, ESET и др.) часто ошибочно принимают его за вирус — обычно пишут `Trojan:Win32/Wacatac.B!ml` или похожие названия.

> **Это 100% ложное срабатывание.** Эвристический анализ антивируса реагирует на то, как упакован `.exe`, а не на его поведение. Если вы скачали архив со страницы [Releases](../../releases/latest) этого репозитория, исходный код открыт, и вы можете его проверить.

| Ситуация | Что делать |
|----------|------------|
| Файл на месте | Добавить папку с программой в исключения Defender |
| Файл уже удалён | Восстановить через Журнал защиты |
| Не хотите добавлять всю папку | Нажать «Разрешить на устройстве» в окне угрозы |

##### Как добавить папку в исключения

1. Нажмите `Пуск`, начните вводить `PowerShell`, найдите **Windows PowerShell**, нажмите по нему **правой кнопкой мыши** и выберите **«Запуск от имени администратора»**.
2. Выполните команду ниже, заменив путь на папку, куда вы распаковали программу (например, `C:\Program Files\SuperDictate` или `C:\Users\ВашеИмя\Downloads\SuperDictate`):

   ```powershell
   Add-MpPreference -ExclusionPath "C:\Путь\К\Папке\SuperDictate"
   ```

3. Нажмите Enter. Готово — Defender больше не будет трогать эту папку.

##### Если файл уже был удалён антивирусом

- Зайдите в **Защитник Windows** → **Защита от вирусов и угроз** → **Журнал защиты**.
- Найдите `SuperDictate.exe` и нажмите **«Восстановить»**.

##### Альтернатива

Если не хотите добавлять всю папку в исключения, нажмите **«Подробнее»** в окне угрозы и выберите **«Разрешить на устройстве»**.

##### Долгосрочное решение

Вы можете помочь проекту, отправив файл в Microsoft как ложное срабатывание через официальную форму. Чем больше пользователей это сделает, тем быстрее Defender перестанет ругаться на приложение в глобальной базе.

### Linux

Поддерживается графическая сессия X11. В Wayland глобальные хоткеи и симуляция клавиш не работают — это ограничение pynput, не приложения (см. раздел «Известные ограничения»).

**Вариант 1. Готовый релиз (рекомендуется)**

1. Скачайте `SuperDictate-Linux.tar.gz` со страницы [Releases](../../releases/latest).
2. Установите системные зависимости.

Ubuntu / Debian / Mint:

```bash
sudo apt update
sudo apt install -y python3-tk libportaudio2 xclip \
                    libayatana-appindicator3-1 \
                    gir1.2-ayatanaappindicator3-0.1
```

Fedora:

```bash
sudo dnf install -y python3-tkinter portaudio xclip \
                    libayatana-appindicator-gtk3
```

Arch / Manjaro:

```bash
sudo pacman -S tk portaudio xclip libayatana-appindicator
```

3. Распакуйте и запустите:

```bash
tar -xzf SuperDictate-Linux.tar.gz
cd SuperDictate
./SuperDictate
```

Модель (~850 МБ) скачается при первом запуске.

**Вариант 2. Из исходников**

```bash
# 1. Системные зависимости (см. блок выше по вашему дистрибутиву)

# 2. Python-зависимости и запуск
git clone https://github.com/Biggant13/SuperDictateWin.git
cd SuperDictateWin
python3 -m venv .venv
source .venv/bin/activate
```

Требования: Linux с X11, Python 3.10+, микрофон, интернет для первой загрузки модели.

### Первый запуск

Приложение свернётся в системный трей (Windows: правый нижний угол; Linux: appindicator в верхней панели — в GNOME может потребоваться расширение AppIndicator).

- Зажмите `F9` → говорите → отпустите. Текст распознается и вставится в активное окно.
- Левый клик по иконке в трее → **Настройки** — можно сменить хоткей, положение оверлея, громкость звука.

### Файлы конфигурации

| Файл | Где лежит | Назначение |
|------|-----------|------------|
| `config.json` | рядом с `.exe` (Windows) / рядом с бинарником (Linux) / в корне проекта (из исходников) | Настройки (хоткей, язык, звук). Создаётся автоматически при первом запуске |
| `stats.json` | там же | Статистика распознанных слов. Не коммитится в git |
| `gigaam-v3-e2e-rnnt-onnx/` | там же | Скачанная модель. При первом запуске ~850 МБ |

## ⚠️ Известные ограничения

- **Linux / Wayland**: глобальные хоткеи и симуляция клавиш не работают. Причина — политика безопасности Wayland, которая запрещает приложениям перехватывать клавиатуру и эмулировать ввод. Решение — запуск в сессии X11. Поддержка Wayland запланирована отдельно.
- **Linux / GNOME**: appindicator может быть скрыт по умолчанию. Установите расширение AppIndicator или используйте другое окружение рабочего стола.
- **Первый запуск**: требуется интернет для скачивания модели (~850 МБ). Дальше приложение работает полностью офлайн.

### [Unreleased] - Улучшение стабильности и логирования

**Логирование и отладка:**
- Добавлен модуль `core/logger.py`. Теперь все системные сообщения и ошибки записываются в файл `superdictate.log` рядом с исполняемым файлом (или в корне проекта).

**Воспроизводимость сборки:**
- Версии всех библиотек в `requirements.txt` жестко зафиксированы (через `==`). Это гарантирует, что приложение будет собираться и работать одинаково стабильно в будущем, даже если выйдут новые версии зависимостей.
- Инструменты для разработки и сборки (например, `PyInstaller`) вынесены в отдельный файл `requirements-dev.txt`, чтобы не засорять окружение обычных пользователей.
- GitHub Actions переведен на использование `requirements-dev.txt` для автоматических сборок.

### [v1.3.2] - Обновление документации (текущая стабильная)

- В README добавлен раздел с решением проблемы ложных срабатываний Windows Defender (инструкция по добавлению программы в исключения).

### [v1.3.1] - Хотфикс (текущая стабильная)

**Исправление критических ошибок:**
- Исправлено падение приложения при первом запуске собранной версии (`.exe` или Linux-бинарник) в момент скачивания модели. Ранее процесс завершался с ошибкой `AttributeError: 'NoneType' object has no attribute 'write'`.
- Отключены прогресс-бары библиотеки `huggingface_hub` (которая использует `tqdm`). В оконном режиме (без консоли) они пытались писать в несуществующий поток вывода и вызывали краш.
- Добавлена глобальная страховка: если приложение запущено без консоли, потоки `sys.stdout` и `sys.stderr` перенаправляются в `devnull`. Это защищает от подобных ошибок в любых сторонних библиотеках.

**Прочее:**
- Папка `dist/` (локальные артефакты сборки PyInstaller) исключена из git-трекинга и добавлена в `.gitignore`. Теперь локальные сборки не засоряют историю коммитов.

### [v1.3.0] - Кроссплатформенность и CI/CD

**Поддержка Linux (новая платформа):**

- Добавлен полноценный порт для Linux (X11). Программа работает на Ubuntu 22.04+, Debian 12+, Fedora 38+ и других современных дистрибутивах.
- Платформозависимый код вынесен в отдельный слой `core/platform/` с абстракцией `BasePlatform`:
  - `windows.py` — прежняя реализация через `ctypes.windll` (без изменений в поведении).
  - `linux.py` — реализация через `pynput` и `tkinter` (симуляция клавиш, настройка оверлея без захвата фокуса).
  - `__init__.py` — фабрика `get_platform()`, выбирающая бэкенд по `platform.system()`.
- Вся бизнес-логика (аудио, распознавание, форматирование, статистика, трей) осталась общей для обеих ОС — дублирования кода нет.

**Совместимость и системные зависимости:**

- На Linux требуются системные пакеты: `python3-tk`, `libportaudio2`, `xclip`, `libayatana-appindicator3-1` (инструкции по дистрибутивам — в разделе «Установка → Linux»).
- `core/config.py`: исправлен `BASE_DIR` для frozen-режима — теперь `config.json` создаётся рядом с исполняемым файлом, а не в родительской папке.
- `SuperDictate.spec` стал платформо-зависимым: разные `hiddenimports` для `pynput` (`_win32` / `_xorg`) и `pystray` (`_win32` / `_xorg`) в зависимости от ОС сборки. `config.json` теперь опционален — если его нет в исходниках, он создаётся при первом запуске.

**CI/CD:**

- Добавлен GitHub Actions workflow (`.github/workflows/build.yml`) с матричной сборкой:
  - `windows-latest` → `SuperDictate-Windows.zip`
  - `ubuntu-22.04` → `SuperDictate-Linux.tar.gz` (сборка на 22.04 для совместимости с glibc 2.35+)
- Публикация релиза автоматическая: при пуше тега `v*` создаётся GitHub Release со всеми артефактами и авто-сгенерированными release notes.
- Возможен ручной запуск из вкладки Actions (`workflow_dispatch`) — для проверки сборки без релиза.

**Прочее:**

- `stats.json` исключён из git-трекинга (это runtime-данные, а не исходники). Добавлен в `.gitignore`.

**Ограничения:**

- Linux-версия требует графическую сессию X11. В Wayland глобальные хоткеи и симуляция клавиш не работают из-за политики безопасности — поддержка Wayland запланирована отдельно.
